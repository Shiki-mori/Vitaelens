## 第一步：添加文件解析依赖

在 `pom.xml` 中增加：

```xml
<!-- PDF 解析 -->
<dependency>
    <groupId>org.apache.pdfbox</groupId>
    <artifactId>pdfbox</artifactId>
    <version>3.0.1</version>
</dependency>

<!-- DOCX 解析 -->
<dependency>
    <groupId>org.apache.poi</groupId>
    <artifactId>poi-ooxml</artifactId>
    <version>5.2.5</version>
</dependency>
```

刷新 Maven。

## 第十步：测试接口

启动项目，用 curl 或 Apifox 测试。

### 上传简历

先准备一份 PDF 或 DOCX 简历文件，然后执行：

```bash
curl -X POST http://localhost:8080/api/resumes/upload \
  -H "Authorization: Bearer MyToken" \
  -F "file=@/path/to/your-resume.pdf"
```

返回类似：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "fileName": "resume.pdf",
    "parsedText": "张三 | 求职意向：XX工程师\n\n教育背景\nXX大学 计算机科学与技术 本科 20XX-20XX\n...",
    "textLength": 1234,
    "createdAt": "20XX-01-01T00:30:00"
  }
}
```

### 查询列表

```bash
curl http://localhost:8080/api/resumes \
  -H "Authorization: Bearer MyToken"
```

### 删除简历

```bash
curl -X DELETE http://localhost:8080/api/resumes/1 \
  -H "Authorization: Bearer 你的token"
```

## 常见问题

**PDF 解析返回空文本**：说明简历是纯图片扫描版，没有文字层。这种情况下代码应该抛出异常，提示用户上传可解析的版本。

**DOCX 中文乱码**：`XWPFDocument` 默认用 UTF-8，正常不会乱码。如果出现乱码，检查文件本身是否损坏。

**文件路径找不到**：检查 `upload-dir` 配置和实际目录是否一致，在 `UploadConfig.init()` 中已经自动创建目录。
