使用 H2 数据库。  
H2 数据库是一个Java编写的轻量级嵌入式数据库，经常用于测试环境。启动快，不影响真实数据库环境，不需要额外安装数据库，适合自动化测试。

## 配置变更

### `pom.xml`增加 `h2`:

```xml
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>test</scope>
</dependency>
```

### 新增 [application-test.yml](../../vitaelens-backend/src/test/resources/application-test.yml)，[schema-h2.sql](../../vitaelens-backend/src/test/resources/sql/schema-h2.sql)

部分测试配置说明：

```yaml
url: jdbc:h2:mem:vitaelens_test;MODE=MySQL;DATABASE_TO_LOWER=TRUE;NON_KEYWORDS=USER;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE
```

`mem`：内存模式。测试开始时创建数据库，测试结束后数据库自动销毁。  
`DATABASE_TO_LOWER=TRUE;`：将数据库对象名称统一转换为小写存储。select * from USER 将自动匹配`user`。  
`NON_KEYWORDS=USER;`：将`USER`从 H2 的保留关键字列表中移除，允许直接使用 `USER`作为表名、列名。  
`DB_CLOSE_DELAY=-1;`：设置数据库关闭延迟时间，-1表示永不自动关闭数据库，除非进程中止或显式调用`shutdown`方法。  
`DB_CLOSE_ON_EXIT=FALSE`：当JVM退出时，不自动关闭数据库。

以上配置适用于嵌入式持久化数据库场景。常见于Spring Boot 单元测试，能显著减少因连接管理导致的异常。

H2 数据库内置一个固定的管理员账户，默认用户名是 `sa`，密码是空。

>`sa` 表示 `system administrator`，系统管理员。
