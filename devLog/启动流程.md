# Docker纪元

## 启动

```bash
cd ~/CodeProject/Vitaelens/deploy

# 首次或改过 Dockerfile / 依赖时带构建
docker compose up -d --build

# 日常启动（镜像已构建过）
docker compose up -d
```

访问：

| 服务 | 地址 |
|------|------|
| 前端 | http://localhost:8088 |
| 后端 | http://localhost:8080 |
| MySQL | localhost:3307 |
| Redis | localhost:6379 |

后端首次启动大约需要 30 秒，再访问登录。

## 停止

```bash
cd ~/CodeProject/Vitaelens/deploy

# 停止并移除容器（数据卷 / mysql-data、redis-data 会保留）
docker compose down
```

只停不删容器：

```bash
docker compose stop
```

再启动：

```bash
docker compose start
```

## 常用查看

```bash
docker compose ps          # 运行状态
docker compose logs -f backend   # 后端日志
docker compose logs -f frontend  # 前端日志
```

`docker compose down -v` 会删命名卷，慎用；当前 MySQL/Redis 数据主要在 `deploy/mysql-data`、`deploy/redis-data` 目录里。
